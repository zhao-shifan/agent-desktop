接入设置

选择服务商后自动填好地址和模型，你只需粘贴对应的 API Key。配置只保存在本机浏览器，不上传任何服务器。

开启后 AI 可以联网搜索、抓网页、读本地文件；命令执行默认关闭。聊天框的「🛠 工具」按钮可随时开关。

手机扫码使用

扫一扫打开 GitHub Pages 在线手机版——不需要电脑开机，任何时候都能用。
打开后建议在浏览器菜单里「添加到主屏幕」，即可像 App 一样全屏使用。
